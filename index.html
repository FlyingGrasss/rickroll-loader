Rickroll Loader plain HTML · CSS · JS

Proof of concept

Every page switch is a rickroll.

Pick another page above. The loader returns for about 1.2 seconds, complete with a silent YouTube cameo, and only then does the next section appear.

First load runs the full 2.5-second version. The skip button is there for the impatient.

About

Small, static, and deliberately annoying.

This demo uses no build step, no package manager, and no framework. Four files: HTML, CSS, JavaScript, and a README.

If YouTube cannot load within 1.5 seconds, the video area turns into a spinning cassette placeholder, so the joke keeps working offline.
